#  Vinci — Concessionária de Veículos

O **Vinci** é uma aplicação web desenvolvida para simular a interface e o catálogo interativo de uma concessionária de veículos. O projeto foca no uso de componentes reativos no Vue 3, estilização responsiva com Tailwind CSS e navegação via Vue Router.

---

##  Guia de Navegação e Testes

Para avaliar as funcionalidades implementadas e navegar pelas telas ativas do projeto, utilize os seguintes caminhos:

1. **Navegação Principal (Header):**
* **Menu "Veículos":** Ao clicar em **Veículos** no topo, o **Mega Menu** interativo é expandido, exibindo as opções do catálogo.
* **Botão "Home":** Clique em **Home** a qualquer momento no cabeçalho para retornar à página inicial do site.


2. **Acesso à Tela de Detalhes do Veículo:**
* **Primeiro Veículo do Catálogo:** Na página inicial, vá até o primeiro modelo de carro e clique no botão **"Conheça o veículo"** (ou **"Conheça"**). Esse botão redireciona para a tela dedicada de detalhes do veículo (`/infocar1`).


*(Obs: Os demais botões de veículos e seções secundárias são ilustrativos para compor o layout do catálogo).*
